# mii-process-models

**Ziel des Repositories**<br>
Dieses Repository dient der zentralisierten Ablage, Pflege und Weiterentwicklung von Prozessmodellen der MII, die die übergreifenden Prozesse der verteilten Infrastruktur darstellen. Zudem soll eine nachvollziehbare Versionierung und Dokumentation von Änderungen ermöglicht werden. 

- Die Darstellung der Prozesse erfolgt auf 3 Ebenen nach [BPMN v2.0 Standard](https://www.omg.org/spec/BPMN) und mit einem zunehmenden Detaillierungsgrad.
- Die Ablage der Prozessmodelle folgt diesem Schema in den Ordnern der Ebenen 1 bis 3.
- Erläuterungen zu den Prozessmodellen und zur Modellierung sind im Begleitdokument zu finden.

**Anmerkungen zu Prozessmodellen**<br>
Bei Anmerkungen zu einzelnen Prozessmodellen kann ein Issue entsprechend der Beschreibung in "Issue Guide EXTERN" erstellt werden. Eingehende Issues werden von der TF Prozessmodelle geprüft und bearbeitet.
