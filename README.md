# mii-process-models
- Repo für beschlossene MII Prozessmodelle, die die übergreifenden Prozesse der verteilten Infrastruktur darstellen
- beschlossene Modelle auf main branch anlegen
- Darstellung der Prozesse auf 3 Ebenen
- bpmn 2.0 Modelle (ggf. Verlinkung auf bpmn standard und tools)
- Näheres zu Prozessen - Verlinkung Begleitdokument und Prozesslandkarte; Verlinkung der aktuellsten Versionen der Modelle über eine Gesamtübersicht
- contribution-prozess beschreiben; vom Anlegen über Versionierung der Modelle in github
